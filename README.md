# Overview
This repository provides the implementation for the paper titled “Machine learning modeling of hit-into-play probability and quantification of pitch sequence effects." This paper is a revised version of the paper entitled “Counterfactual Optimization of Baseball Pitch Sequences and Estimation of Its Impact on Season-Level Statistics.”

The paper conducted a machine learning–based analysis to quantify the importance of preceding pitches and deepen the tactical understanding of baseball.  A Transformer-based model was designed and trained to predict whether a target pitch would result in an in-play outcome or a swinging strikeout. Based on the model, two analyses were conducted: an ablation study to evaluate the contribution of preceding pitches to predictive performance and a replacement analysis to quantify changes in predicted in-play probability when individual pitches were replaced by alternatives. 

Please refer to the original paper [1] for details.

# Installation
This project is designed to be run in Python environment.
The procedure for reproducing the analyses in this study is as follows:

1. Run the programs `data_downloader.py` and “dataset_generator.py” to download and process the MLB data used in the analysis and generate the dataset. This will automatically generate files in the “dataset” and “data” folders.
  
2. To prepare for the replacement analysis in Analysis 2, run `pitch_type_act_inzone.py,` `pitch_type_act_outzone.py,` and `pitch_type_sim.py.` These programs generate candidate replacement pitches under each respective condition.

3. Run `base_model_training_and_testing.py` to train and test the base model.
   
4. Run `ablation_study.py` to perform Analysis 1.

5. Run `analysis1.m` and `analysis2.m` to summarize and visualize the analysis results. Before running these programs, please save the outputs from the corresponding notebooks above in the `./results` folder (generated by the ipynb files) under the names `analysis1` and `analysis2`, respectively.
